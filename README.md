# Community Builders of Pecan Grove · student play-test

A test copy of the kids' civic game from the Know Your Data Center hub, for students to play and review before the public launch.
English: `index.html` · Spanish: `espanol.html`. Built by `tools/make_playtest.py` in the hub project; do not edit here.

The game saves progress and feedback drafts in the player's browser (localStorage). If an endpoint is configured, anonymous feedback automatically backs up as players progress. The feedback panel also downloads an Excel-compatible backup. Shared computers have a New player control for separate game and feedback sessions. No names or contact details are requested.
