The earlier automatic Drive-upload request was changed by the owner's explicit instruction to implement opt-in sending. Drive remains the collector for an explicitly sent note or an adult-enabled score-sharing option. “Saved on this device” must never be used to promise that opted-in scores remain only on the device. Review the intro wording for that distinction.

Turning sharing off prevents future score collection and withdraws unsent score records; it cannot recall records already received by the team. New player resets both sharing switches and separates the next person's drafts. The score-only payload has no name field. Free-text contact scrubbing is a heuristic, so the preview still asks the grown-up to remove names and check any remaining personal details. The collector also receives technical record metadata, including random station/player/entry codes, revision, timestamps and build; see [the complete sending contract](feedback-endpoint.md). Ali approved the privacy wording and receiver changes. The root agent reports that the existing receiver was upgraded at the same endpoint, with the private workbook setting retained: HTTP checks verified the 64 KiB limit, 1,200-character limit, server contact scrubbing and same-revision clean-hash acknowledgement. Seven upsert, invalidation and separate-anonymous-player checks passed, with CORS enabled. The browser confirmation did not return a deployment version number, so none is recorded. These receiver checks do not establish publication of the game; the public site has not yet been published in this modernization run.
