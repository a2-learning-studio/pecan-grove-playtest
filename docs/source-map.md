## Implementation decisions and bounds

- The map preserves its geographic 1376:768 aspect at every width, deterministically separates stop discs by at least 44px, and provides chapter hulls, zoom/pinch and four-direction plate/disc collision handling. Below 480px, Map/List mode provides a separate readable route. Geometry doubles verify those invariants; native-browser touch/visual fit remains independent.
- Reference Stops 1/2 provide explicit state snapshots: chosen sign objects, found/tapped signs and view; and selected neighbors, worry number, tile ordering, selections and answers. Restoring a result does not save or upload a second completion.
- Language changes now run in place through `CommunityBuilders.setLanguage()`: document language, URL, locale closures and voice lookup change, and the same stop is rebuilt. Full-core tests verify a partial-game EN→ES→EN round trip for every stop and keep the introductory gate paused. The older short-lived handoff remains only for compatibility with prepared links.
- All fifteen stops now have native controllers. Stops 3–15 use version2 models: neighbor listening/pair/quiz state; claims/source classifications; change chains; desk attempts; speaker-card selections/helper timers; shared-solution/reaction state; chair attempts; checked/linked fixes/dialogs; weighed paths/choices; promise revisions/clarity; poster/source/date/replaced tray cards; checked promises/follow-ups; and future-plan/check/invitation phases. They rebuild localized DOM directly without replaying inputs. Legacy actions-v1 records retain a tested compatibility route. The 26 native coarse-phase cases for Stops 3–15 pass in both languages, including actual open dialogs, exact model/visible-state equality and live language round trips without score writes.
- All 15 stops also have completed-round tests in English and Spanish. Each compares the actual result screen and original result messages after resume and a language round trip, and verifies that no second score write occurs. Snapshots retain the original round baseline and result metadata for this purpose.
- Authored vector markup is constructed through `engine/authored-markup.js` and an allowed SVG/attribute set. Every stop uses the shared helper; stops contain no HTML assignment sinks. First gameplay actions for all stops are also tested with `innerHTML` assignment disabled and runtime exceptions captured. This check does not by itself establish native-browser Trusted Types or CSP behavior.
- Stops subscribe to shared scoped actions; their lifecycle disposes subscriptions, timers and document listeners when leaving. Keyboard activation bypasses pointer double-tap guards in Stops 2, 13 and 15. Stop 8's temporary pointer guard is limited to its own active root and removed on leaving.
- Stop 1 discoveries default to a nonmodal callout. Grown-ups can choose classic discovery cards; Library/Class mode selects that presentation by default.
- Game map images use responsive widths; crops advertise their magnification to image selection.
- Stop 2 measures stage width/available height and question-strip height with ResizeObserver. Compact layouts keep the strip in normal flow and provide a 56px pinned Ask shortcut that hides when it would intersect painted art or the speech bubble. Short layouts disable the sticky bubble. A geometry-double regression verifies sizing, collision prevention and cleanup; real-browser geometry remains a separate acceptance check.
- Lighthouse values in the attached spec are observations of its intro audit. They must be remeasured on the generated release, not treated as permanent guarantees or as coverage of every stop.

The owner-authorized source is the full canonical project. Legacy `_publish/pecan-grove-playtest` is an older Pages export; the modern release is generated by the Vite build and published separately. Do not replace the full project with that export or publish backend administration files.

Current source tests cover authored scoring in both languages, all-stop module starts, all-stop partial and completed state/language restoration, saved-slot reloads, reference explicit snapshots, scoped actions, listener disposal, exact-target fullscreen labels, and JSON parity. Media-double tests check narration clocks separately from actual speaker playback. Browser layout and device tests are recorded by the root task separately; no DOM-double result is presented as hardware or visual evidence.
